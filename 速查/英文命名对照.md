# 项目里出现过的英文名字（按阶段分组）

> 用途：看到不认识的英文标识符，先来这里查，再往下读代码。
> 规矩：以后我给新的英文名字，**第一次出现时先说中文意思 + 为什么叫这个名字**。

## 0. 怎么查（先按阶段定位）

| 阶段 | 主要在哪个文件 | 这阶段在学什么 | 查第几节 |
|---|---|---|---|
| 阶段 1 | `阶段1_重写/task.py` | dataclass / 自定义异常 / JSON 持久化 / 增删改查 | 第 2 节 |
| 阶段 2 | `阶段2_重写/llm_config.py` | `.env` 解析 / Config / FakeClient / create_client | 第 3 节 |

## 1. 通用词根（跨阶段，任何阶段都可能出现）

Python 的命名基本是"小写 + 下划线"（叫 snake_case，蛇形命名）。很多名字就是两三个词根拼起来。

| 词根 | 中文 | 例子 |
|---|---|---|
| `get` / `set` | 取 / 设 | `get(task_id)` 按编号取一条；`setdefault` 没有才设 |
| `load` / `save` | 加载（文件→内存）/ 保存（内存→文件） | `_load()` / `_save()` |
| `read` / `write` | 读 / 写（直接对文本） | `read_text()` / `write_text()` |
| `parse` | 解析：把字符串拆成结构 | `parse_due()` |
| `normalize` | 归一化：统一成一种标准格式 | `_normalize_due()` |
| `create` | 创建 | `create_client()` |
| `add` / `remove` | 添加 / 移除 | `add()` / `list.remove()` |
| `include` | 包含 | `include_done`（是否包含已完成的） |
| `done` | 已完成 | `done` 字段 |
| `default` | 默认值 | `default_factory` |
| `factory` | 工厂：专门"造东西"的函数 | `default_factory` = 造默认值的函数 |
| `store` | 存储 / 仓库（不是"商店"） | `TaskStore` |
| `due` | 到期 / 截止日 | `due="2026-10-20"` |
| `days_left` | 剩余天数 | `days_left()` |
| `describe` | 描述：转成一行文字 | `describe()` |
| `upcoming` | 即将到来的 | `upcoming(7)` |
| `provider` | 服务提供方（哪家模型厂商） | `provider="deepseek"` |
| `client` | 客户端：帮你发请求的对象（不是"顾客"） | `client.chat...` |
| `fake` | 假的 / 测试替身 | `FakeClient` |
| `completion` | **补全 / 续写**（不是"完成"） | `completions.create(...)` |
| `response` | 响应：服务器返回的东西 | `_response()` |
| `preset` | 预设（pre 预先 + set 设定） | `preset = PROVIDERS[...]` |
| `script` | 剧本：预先写好的台词 | `script=["第一句"]` |
| `calls` | 调用记录（每次请求的留档） | `client.calls` |
| `env` | environment 的缩写：环境（这里指环境变量） | `os.environ` |
| `dotenv` | ".env 文件"的读法（dot + env） | `load_dotenv` |
| `api key` | 接口密钥（你的账号凭证） | `STUDYMATE_API_KEY` |
| `base_url` | 基础网址（接口的根地址） | `https://api.deepseek.com` |
| `model` | 模型 | `deepseek-chat` |
| `id` | 编号 / 标识 | `task_id` |
| `kwargs` | keyword arguments 的缩写，读作 "K-words"：任意关键字参数 | `**kwargs` |
| `args` | arguments 的缩写：任意位置参数 | `*args` |
| `asdict` | as dict，"当作字典来" | `asdict(task)` |

## 2. 阶段 1：任务数据层

| 名字 | 中文 | 出现位置 |

| `title` | 标题 | `Task.title` |

### 2.2 异常与文件

| 名字 | 中文 | 出现位置 |
|---|---|---|
| `TaskError` | 任务相关错误（自定义异常基类） | `raise TaskError(...)` |
| `TaskNotFoundError` | 找不到任务（子类） | 按编号查不到时抛 |
| `raise` / `except` | 抛出 / 捕获异常 | 等价 C 的 `return -1` + 到处判错 |
| `json` | JSON 编解码模块 | 落盘/读回 |
| `dumps` / `loads` | 对象 → 字符串 / 字符串 → 对象 | `json.dumps()` / `json.loads()` |
| `asdict` | dataclass → dict | 写 JSON 前转换 |
| `pathlib` / `Path` | 路径对象 | `Path("tasks.json")` |
| `exists()` | 文件是否存在 | 读之前先判断 |
| `with_suffix` | 换掉文件后缀 | `.json` → `.tmp`（临时文件） |
| `replace()` | 覆盖替换（原子写入） | 临时文件 → 正式文件 |
| `encoding` / `utf-8` | 编码 / 统一码 | 中文必须指定 utf-8 |
| `strip` / `split` | 去两端空白 / 按分隔符切 | 解析每行文本 |
| `fromisoformat` / `isoformat` | 字符串 ↔ 日期 | `date.fromisoformat("2026-11-09")` |

## 3. 阶段 2：配置 + 模型客户端

> 文件：`阶段2_重写/llm_config.py`；结构位置见 `阶段2_重写/结构总览.md` 的"配置层 / 客户端层"。

| 名字 | 中文 | 出现位置 / 注意 |
|---|---|---|

## 4. 阶段 3：工具注册表 + agent 循环

> 文件：`阶段3_重写/tools.py` + `agent.py`；结构位置见 `阶段3_重写/结构总览.md` 的"工具层 / 循环层"。

### 4.1 核心名词

| 名字 | 中文 | 怎么理解 / 为什么叫这个 |
|---|---|---|
| `tool` | 工具 | 模型"能调用的一个函数"。对模型来说它是"本事"，对我们来说就是普通 Python 函数 |
| `tool call` | 工具调用 | 模型不直接做事，而是**回一句话请求**我们去执行；不是"打电话" |
| `tool_call_id` | 工具调用编号 | 每次调用一个编号，工具结果靠它对应回"这是回你第几个请求" |
| `registry` | 注册表 | register（登记）+ -y（名词后缀）= "登记册"；`ToolRegistry` = 工具登记册 |
| `schema` | 模式 / 结构描述 | 读作 "SKEE-muh"；这里指"这个工具长什么样"的 JSON 描述（名字、参数、类型） |
| `JSON Schema` | JSON 结构描述标准 | 一种用 JSON 描述"数据应该长什么样"的通用格式，OpenAI 接口就吃这个 |
| `dispatch table` | 分发表 / 函数指针表 | 按名字查到该调哪个函数；C 里就是"函数指针数组"，替代一长串 `switch` |
| `system prompt` | 系统提示词 | prompt = 提示词；system = 系统层，每次请求都放在最前面，用来定身份和规矩 |
| `hallucination` | 幻觉 | 模型一本正经地编造事实；工具调用就是用来压它的 |
| `agent` | 智能体 | 这里指"会循环思考 + 会调工具"的程序，不是"代理人" |

### 4.2 代码里的名字

| 名字 | 中文 | 出现在哪 / 干什么 |
|---|---|---|
| `Tool` | 工具（一条记录） | `tools.py`：存 name / description / func / parameters |
| `ToolRegistry` | 工具注册表 | `tools.py`：`tools: dict[str, Tool]` |
| `.tool(...)` | 登记方法 | 当**装饰器**用：`@reg.tool("描述")` |
| `schemas()` | 全部工具描述 | 返回列表，原样传给模型的 `tools=` 参数 |
| `execute()` | 执行 | 名字 → 参数 → 调用函数 → 结果转字符串 |
| `parameters` | 参数定义 | schema 里描述"有哪些参数、什么类型、哪些必填" |
| `properties` | 属性表 | JSON Schema 里放每个参数的字段 |
| `required` | 必填项 | 没有默认值的参数才会进这里 |
| `inspect.signature` | 查看函数签名 | inspect = 检查；signature = 签名（函数名 + 参数表） |
| `type hints` | 类型标注 | `a: int` 里的 `int`；从它自动推出 JSON 类型 |
| `decorator` | 装饰器 | 函数上面 `@xxx` 那一行，本质是"把函数包一层再返回" |
| `max_steps` | 最大步数 | step = 步；防止 agent 无限循环、无限烧钱 |
| `role` | 角色 | 消息是谁说的：`system` / `user` / `assistant` / `tool` |
| `assistant` | 助手 | 模型的角色名（不是你） |
| `trim` | 裁剪 | `_trim_history`：历史太长时丢掉最早的几条 |
| `retry` / `backoff` | 重试 / 退避 | 失败后等一会儿再试，间隔逐次拉长（参考版有，我们砍了） |
| `callback` / `on_event` | 回调 / 事件通知 | 让界面层知道"正在调工具"；我们砍了 |
| `confirm` | 确认 | 危险操作前问用户一句；我们砍了 |
| `dangerous` | 危险的 | 工具标记，配合 `confirm` 用；我们砍了 |

### 4.3 两个容易混的词

| 词 | 中文 | 区别 |
|---|---|---|
| `parameter`（形参） | 函数定义里的参数 | `def add(a: int, b: int)` 里的 a、b |
| `argument`（实参） | 调用时真正传进去的值 | 模型给的 `{"a": 2, "b": 3}` |

> 记住：**定义时叫 parameter，调用时叫 argument**；日常口语里中文都叫"参数"，看英文时才知道在说哪一边。

## 5. 跨阶段：最容易误解的 12 个

| 名字 | 你以为 | 实际 | 首见 |
|---|---|---|---|
| `completion` | 完成 | **补全/续写**——模型的本质是"接着往下写" | 阶段 2 |
| `client` | 顾客 | **客户端对象**（发请求的那一端） | 阶段 2 |
| `store` | 商店 | **存储 / 仓库** | 阶段 1 |
| `fake` | 假的、没用 | **测试替身**：形状和真的完全一样 | 阶段 2 |
| `provider` | 提供者（人） | **服务商标识**（`deepseek` / `fake`） | 阶段 2 |
| `preset` | 预置？ | pre 预先 + set 设定 = **预先配好的一套值** | 阶段 2 |
| `describe` | 描述（动作） | **转成人类可读的一行文字** | 阶段 1 |
| `due` | 应有的 | **到期 / 截止**（`deadline` 才是"最后期限"） | 阶段 1 |
| `upcoming` | 上来的 | up（来临）+ coming（正在来）= **即将到期** | 阶段 1 |
| `dumps` / `dump` | 一样 | `dumps` 加 s = 返回**字符串**；`dump` 写进**文件对象** | 阶段 1 |
| `_load` 的下划线 | 装饰？ | **单下划线 = 内部使用**，约定"别从外面直接调" | 阶段 1 |
| `__init__` 双下划线 | 只是名字 | **协议方法**：Python 会自动调用（`Config(...)` 就调它） | 通用 |

## 6. 读代码时的三步

1. **定位阶段**：这段代码在哪个 `阶段N_` 目录？→ 查第 0 节的表，跳到对应节。
2. **拆词根**：还看不懂就回第 1 节拆（`load_dotenv` = load + dotenv = "加载 .env 文件"）。
3. **还不行就问**——问的时候把那一行贴出来，比描述"那个函数"更快。

## 7. 我以后怎么给新词

新英文名字第一次出现时，我会写成：

> `preset`（**预设**：pre 预先 + set 设定，指"预先配好的一套默认值"）

然后再用它。缩写（如 `env`、`kwargs`、`api`、`JSON`）会展开全拼一次。
每开一个新阶段，收尾时把该阶段的新词补进对应的第 N 节。
