# 字符串 / 路径 / 环境变量 速查表

阶段 2 用得到的那一小块，够用就行。**看这张表比跑脚本快**，跑脚本只在"想确认某个行为"时才需要。

> ⚠️ **粘贴说明**：第七节里的 `>>>` 是交互提示符，不是代码。粘进 Console 前删掉 `>>>` 和输出行；或者右键文件 → `Run File in Python Console`，变量会预加载进去，再逐行敲。

## 一、Path（路径对象）

`path` 参数是 `Path` 对象，不是字符串。它自带一堆方法，不用自己拼字符串。

| 写法 | 结果 | 说明 |
|---|---|---|
| `Path("a/b.txt")` | `a\b.txt` | Windows 下也能用 `/`，Path 自动转换 |
| `Path("a") / "b.txt"` | `a\b.txt` | **拼路径用 `/`**，不要用 `+`（`+` 要自己加斜杠） |
| `p.exists()` | `True` / `False` | 文件或目录在不在 |
| `p.read_text(encoding="utf-8")` | `"整段文本"` | 一次读完，等同 open+read+close |
| `p.write_text("内容", encoding="utf-8")` | `None` | 覆盖写；父目录不存在会报错 |
| `p.name` | `"b.txt"` | 文件名（带后缀） |
| `p.suffix` | `".txt"` | 后缀 |
| `p.parent` | `a` | 所在目录 |
| `p.with_name(p.name + ".tmp")` | `a\b.txt.tmp` | **追加**后缀（原子写要用这个） |
| `p.with_suffix(".tmp")` | `a\b.tmp` | **替换**后缀（容易搞错） |

## 二、字符串（`str` 的方法都返回新字符串，原字符串不变！）

| 写法 | 结果 | 说明 |
|---|---|---|
| `"  a  ".strip()` | `"a"` | 去两端空白（空格/制表/换行） |
| `'"a"'.strip('"')` | `'a'` | 去两端的**指定字符**（任意多个，不是配对） |
| `"A=B=C".split("=")` | `['A', 'B', 'C']` | 全拆 → 3 个元素 |
| `"A=B=C".split("=", 1)` | `['A', 'B=C']` | 只拆 1 次 → 值里的 `=` 保住 |
| `"a\r\nb\n".splitlines()` | `['a', 'b']` | 按行拆，换行符不保留 |
| `"#x".startswith("#")` | `True` | 是不是以它开头 |
| `"=" in "K=v"` | `True` | 子串/字符是否存在 |
| `"ABC".lower()` | `"abc"` | 转小写（读环境变量必用） |
| `"-".join(["a", "b"])` | `"a-b"` | 用某个分隔符拼接 |

## 三、环境变量

| 写法 | 行为 |
|---|---|
| `os.environ` | 进程环境变量表，长得像字典 |
| `os.environ["K"]` | 键不存在 → **`KeyError` 直接炸** |
| `os.getenv("K", "默认值")` | 键不存在 → 返回默认值（**读可选配置一律用这个**） |
| `os.environ.setdefault("K", v)` | 键**不存在才**写入；已存在则不动（`.env` 用它） |
| `os.environ["K"] = v` | 无条件覆盖（大多数时候不该用） |

## 四、常用小结构

| 需求 | 写法 |
|---|---|
| 同时拿下标和元素 | `for i, x in enumerate(xs, 1):` |
| 拆成两个变量 | `key, value = pair`（等价 `pair[0]`、`pair[1]`） |
| 条件"任一成立" | `if a or b:` |
| 条件"全部成立" | `if a and b:` |
| 跳过这一轮 | `continue` |
| 结束整个循环 | `break` |
| 判断"是不是 None" | `if x is None:`（**不要** `if not x:`） |

## 五、五个坑（都踩过）

| 坑 | 现象 | 正确做法 |
|---|---|---|
| `s.strip()` 不接住 | 看着写了，其实没效果 | `s = s.strip()`（方法返回新串） |
| `and` 当 `or` 用 | 条件永远不成立，跳过逻辑失效 | "任意一个成立就跳过"用 `or` |
| `split("=")` 不带 `1` | 值里带 `=` 时被切成 3 段，解包报错 | `split("=", 1)` |
| `os.environ["不存在的"]` | `KeyError` | `os.getenv(k, 默认)` |
| `if not x:` 当"是否 None" | 空字符串、空列表也被当成 None | `if x is None:` |

## 六、`load_dotenv` 逐行对照

| 代码 | 作用 | 注意 |
|---|---|---|
| `if not path.exists(): return` | 文件不在就退出 | 别写成 `if path is None`（Path 不会是 None） |
| `text = path.read_text(encoding="utf-8")` | 读成整段字符串 | |
| `lines = text.splitlines()` | 拆成行列表 | 变量名别叫 `line`，它是"所有行" |
| `line = raw.strip()` | 当前行去两端空白 | **必须接住返回值** |
| `if not line or line.startswith("#") or "=" not in line: continue` | 空行 / 注释 / 无等号 → 跳过 | 用 `or`，且后面统一用 `line` |
| `key, value = line.split("=", 1)` | 拆成键和值 | `maxsplit=1` |
| `key.strip()`、`value.strip().strip('"').strip("'")` | 清两端 | |
| `os.environ.setdefault(key, value)` | 不覆盖已有环境变量 | 不是 `=` 赋值 |

## 七、比跑脚本更快的办法：PyCharm 的 Python Console

写代码时"这个方法到底返回啥"最烦，不用写实验文件，直接问控制台：

1. 底部工具条点 **`Python Console`**（不是 Terminal，是 Console）
2. 直接在 `>>>` 后面敲表达式，回车就出结果：

```python
>>> "  a  ".strip()
'a'
>>> "A=B=C".split("=", 1)
['A', 'B=C']
>>> Path("a/b.txt").with_suffix(".tmp")
WindowsPath('a/b.tmp')
>>> from pathlib import Path     # 报 NameError 就先 import 一行
```

3. **更省事**：在编辑器里右键文件 → `Run File in Python Console`。它会把文件里执行过的变量（`text`、`lines`、`demo`…）都留在控制台里，你接着敲：

```python
>>> lines[2]          # 第 3 行长什么样
'KEY=value'
>>> repr(lines[0])
'# 这是注释行'
>>> [l for l in lines if "=" in l]   # 只挑带等号的行
```

> Console 和 Terminal 的区别：Terminal 只是命令行，跑完就退；**Console 是活着的 Python 环境**，变量和 import 都留着，可以一段一段试。这就是"对照着看"最省事的方式。

## 八、字典（`dict`）：`[]` 里放的是"键"，不是"第几个"

**这是最容易混的一点**：`[]` 这个符号，对列表和对字典的意思完全不同。

| 容器的类型 | 写法 | 意思 | 结果 |
|---|---|---|---|
| 列表 `list` | `xs[0]` | 第 0 个**位置** | 第一个元素 |
| 列表 `list` | `xs[-1]` | 倒数第一个 | 最后一个 |
| 字典 `dict` | `d["name"]` | 键 `"name"` 对应的**值** | 值 |
| 字典 `dict` | `d[key]` | 用**变量里的字符串**当键 | 值 |
| 字典 `dict` | `d[0]` | 键是**数字 0**，不是"第 0 个" | 通常 KeyError |

### PROVIDERS 是什么：字典套字典

```python
PROVIDERS = {
    "deepseek": {"base_url": "https://api.deepseek.com", "model": "deepseek-chat"},
    "fake":     {"base_url": "",                          "model": "fake"},
}
```

- **外层**：键是厂商名（字符串），值是"这个厂商的配置字典"
- **内层**：键是字段名（`base_url` / `model`），值是具体内容
- 花括号 `{}` = 字典；`{ "键": 值, ... }` 每一对用冒号隔开、逗号分隔

### 三层取值，一层一层来

```python
PROVIDERS                            # 整张表（外层字典）
PROVIDERS["deepseek"]                # {'base_url': '...', 'model': 'deepseek-chat'} ← 内层字典
PROVIDERS["deepseek"]["model"]       # 'deepseek-chat'                                ← 再取一层
```

`preset = PROVIDERS[provider]` 就是**中间那一步**：
把"这个厂商的小字典"先存到变量 `preset` 里，后面就不用反复写 `PROVIDERS[provider]`。

```python
preset = PROVIDERS[provider]
preset["base_url"]          # 小字典里的默认网址
preset["model"]             # 小字典里的默认模型名
```

### 四个必备操作

```python
"deepseek" in PROVIDERS               # True   ← in 查的是"键"
PROVIDERS["openai"]                   # KeyError ← 键不存在，直接炸
PROVIDERS.get("openai")               # None     ← 不炸，返回 None
PROVIDERS.get("openai", "默认值")      # '默认值' ← 不炸，给默认值
for name in PROVIDERS: print(name)    # deepseek / fake ← 遍历拿到的是键
```

### 两个坑

1. **字典不能用点号取值**：`preset.base_url` ❌ → `AttributeError`。
   （能用 `obj.base_url` 的是 `Config` 那种"对象/dataclass"，不是 dict）
2. **键名拼错不报"拼错"，只报 KeyError**：`preset["Base_url"]` → `KeyError: 'Base_url'`。
   所以阶段 2 才用 `os.getenv("STUDYMATE_BASE_URL", preset["base_url"])` 这种写法——**默认值从预设里取，键名只写一次，不容易拼错**。

### 为什么要有"预设"这层

没有预设表的话，每次跑都得把网址和模型名写全：

```
STUDYMATE_BASE_URL=https://api.deepseek.com
STUDYMATE_MODEL=deepseek-chat
```

有了预设表，用户只需要写一行 `STUDYMATE_PROVIDER=deepseek`，剩下两个自动填。

**优先级：环境变量 > 预设。** 用户显式配了就听用户的，没配才用预设——这就是 `os.getenv(键, 预设值)` 的语义。
