关注点说明
装饰器登记 / 返回原函数登记进 tools；被装饰后函数仍可直接调用
schema 形状 / 必填 / 类型没有默认值的参数才进 required；int → integer、str|None → string
全部工具清单 / 空表schemas() 列出所有工具；空注册表返回 []
JSON 字符串 / dict 入参execute("add", '{"a":2,"b":3}') 和传 dict 都要能跑
四类错误变字符串未知工具 / 坏 JSON / 参数不匹配 / 工具内部异常 → 都返回 "错误：..."
系统提示词 + 今天日期第一条必须是 system，且含今天日期
工具清单传入 / 空表传 None注册表为空时 tools=None，不是空列表
工具调用与回填assistant 的 tool_calls 原样记录；结果以 role="tool" + tool_call_id 对应
一轮多个工具 / 工具报错不崩同一轮两个调用都执行；错误信息回填后模型还能继续
max_steps 兜底模型一直要工具时，最多请求 max_steps 次并返回提示
⑥ 三条设计取舍 ▶

schema 自动生成

函数签名是唯一事实来源。手写第二份，签名一改就两边不一致。

错误变字符串

模型是调用方，它要能读懂并改正。抛异常 = 对话终止，模型永远学不会。

循环 + max_steps

多轮工具调用是 agent 的本质；上限是防死循环的安全带（也是防烧钱）。
